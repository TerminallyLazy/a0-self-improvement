# Automate inert Genesis at the Agent Zero project boundary

When the plugin is enabled, A0 Self-Improvement will default to automatic Genesis enrollment at the message-loop-start seam. The coordinator discovers only context identifiers whose chat metadata names the current Agent Zero project, serializes parallel loops with an owner-only local lock, creates the pre-cutover v3 store when absent, and establishes the permanent two-slot Null Activation Profile at revision zero for every missing project context. This replaces command-line setup as the primary user experience while retaining `project-genesis` as a recovery/admin tool.

The convenience authority is separate from operator custody. It uses owner-only files and issues exact short-lived grants solely through the automatic Genesis coordinator for `initialize_genesis`; it supplies no work, content, migration, fixture, model, canary, promotion, activation, rollback, or Safety Bypass authority. Null artifacts remain byte-inert. The plugin enablement toggle, the **Set up project Genesis automatically** toggle, project membership, and offline-replay exclusion are all required before mutation. Failure leaves improvement unavailable but never blocks ordinary Agent Zero behavior.

Status and Runtime Composer remain pure reads. Activation Scope, receipts, commands, and later transitions remain context-bound even though discovery is project-grouped, preventing one parallel agent from silently changing another agent's active profile. Chats without a project are not enrolled automatically.
